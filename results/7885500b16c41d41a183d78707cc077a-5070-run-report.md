## 当前判断

GPU 推理链路已经正常工作，篮球专用检测器能够在转播画面中稳定找到大量球员框和篮球框。当前最明显的瓶颈是轨迹 ID 数量仍然远高于真实球员数量，说明需要继续加入相机运动补偿、ReID 和轨迹合并。事件引擎目前输出的是待复核候选，不能直接当作最终得分、篮板或助攻统计。
